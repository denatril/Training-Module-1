Görev 5. Sipariş Özeti Hesaplama

Bu görevi `task-5.js` dosyasında gerçekleştirin.

Satış ekibi, küçük bir sipariş ekranında kullanılacak yardımcı fonksiyonlara ihtiyaç duyuyor. Sistemde bir karşılama mesajı gösteren fonksiyon, parametre alan bir selamlama fonksiyonu ve hesaplama yapan bir fonksiyon hazırlanması gerekiyor.

`task-5.js` içinde aşağıdaki işleri yapın:

Parametresiz bir fonksiyon yazın.
Parametre alan bir fonksiyon yazın.
Geri dönüş değeri olan bir fonksiyon yazın.
İki sayıyı toplayan bir fonksiyon oluşturun.

Amaç, fonksiyon mantığını ve tekrar kullanılabilir kod yazmayı öğrenmektir.

Aşağıdaki kodu al ve görevi tamamladıktan sonra doğruluğunu kontrol etmek için altına yapıştır. Konsola çıktılar yazdırılacaktır.

```javascript
function greet() {
  console.log("Merhaba");
}

function sayHello(name) {
  console.log(`Merhaba, ${name}`);
}

function getSum(a, b) {
  return a + b;
}

console.log(getSum(5, 3));
```
